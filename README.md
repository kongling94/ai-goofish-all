# AI Goofish All

基于 AI Goofish 的统一闲鱼监控与数字商品管理项目。一个 Vue/FastAPI 入口，内部接入固定版本卖家引擎。默认演练，不连接真实闲鱼账号。

> 开发中。功能与验证边界以本 README 为准，不把演练成功等同于真实平台发布或发货成功。
